# Publication boundary / 公开发布边界

吐梨邦宿主处于受邀测试阶段。公开本插件不代表获准公开宿主。禁止在 README、文档、源码示例、提交信息、Issue/PR、Release、附件或 CI 日志中发布宿主安装包链接、更新源地址或可推导下载地址的存储位置；中英文一致。仅通过用户明确授权的测试渠道分发宿主。插件自身的源码和 `plugin.zip` 下载可按已授权范围公开。

The Desktop Pet host is in invitation-only testing. Publishing this plugin does not authorize publishing the host. Do not include host installer links, update feeds, or storage locations revealing those downloads in public files, commit messages, issues, pull requests, releases, assets, or CI logs, in either language. Distribute the host only through explicitly authorized testing channels. Authorized plugin source and plugin ZIP downloads may remain public.
